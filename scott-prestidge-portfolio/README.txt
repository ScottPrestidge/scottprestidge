Scott Prestidge portfolio - deployment build
=============================================

This is a plain static website. No build step, no framework, nothing to install.

FOLDER CONTENTS
  index.html        Landing page (desktop slide layout; on phones, the landing screen only)
  work.html         Phone main page (work, about, contact). On a computer it opens index.html
  buller.html       Full project: Buller Open-Air
  tectonic.html     Full project: Tectonic Resonance
  thesis.html       Full project: Ctrl + Alt + Escape
  404.html          "Page not found" page
  images/           All photos and renders
  fonts/            Inter font (self-hosted, no Google connection needed)
  files/            Scott-Prestidge-CV.pdf (used by the Download CV button)
  favicon.svg       Browser tab icon
  _headers          Netlify caching rules (optional, harmless)

DEPLOY ON NETLIFY (simplest: drag and drop)
  1. Unzip this file.
  2. Go to https://app.netlify.com/drop and sign in (a free account is fine).
  3. Drag the whole unzipped folder (the one that contains index.html) onto the page.
  4. Netlify gives you a live address like https://random-name-123.netlify.app
  5. Optional: Site configuration > Change site name, e.g. scott-prestidge.netlify.app
  6. Optional: Domain management > Add a domain you own.

UPDATING LATER
  Open the site in Netlify > Deploys > drag the new folder onto the "Drag and drop" area.

BEFORE YOU SHARE THE LINK
  - Replace files/Scott-Prestidge-CV.pdf with your updated CV (keep the same file name).
  - Check the LinkedIn link opens your profile.
  - Make sure you have permission to publish the photography (Souki Media / M87 / Red Bull; Snooks+Harper installation views).
